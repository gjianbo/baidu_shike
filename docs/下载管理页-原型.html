设计要点与实现边界

页面定位二级页面，从设置页「下载管理」或长按下载后的提示条进入；不占底部导航。
两个 Tab进行中 / 历史。进行中顶部汇总并发数、总速度与总进度；历史按日期分组，区分完成与失败。
进度来源传输仍交给系统 DownloadManager；页面用 Query 按入队 id 读已下字节 / 总字节，约 1 秒轮询，速度由两次采样差算出。
多任务App 侧控制最多 3 个同时入队，其余显示「排队中」；系统负责后台保活与断点续传，退出 App 不中断。
可用操作取消、失败重试、完成后打开 / 删除记录、清空已完成。不做「暂停 / 继续」——系统下载器不提供 App 主动暂停，取消后重下不保证续传。
存放位置下载 / 拾课/，文件名带时间戳前缀避免覆盖；系统通知设为隐藏，避免与页面进度重复提示。
任务记录入队 id、文件名、来源、大小、状态持久化到本地，重启 App 后仍能恢复列表。
