落地要点（待你拍板后改 Kotlin）

· 中间 cover 现在是 220dp ImageView + bg_audio_disc 圆底，改成自定义 View（onDraw 画纹路 / 标签 / 唱臂）最省依赖，项目无 Lottie。
· 唱片用 ObjectAnimator.ofFloat(0f,360f) 无限线性；暂停用 pause() 保留角度，不 cancel()。
· 唱臂用 ViewPropertyAnimator.rotation() 过渡，支点做 pivotX/Y。
· 状态只绑 update() 里的 player.isPlaying；animator 必须缓存，只在状态翻转时切换——update() 每秒都在跑，不能在里面 new animator。
· 页面关闭 / compact 隐藏封面时要 cancel()，避免无限动画泄漏。
· 浅色 / 深色两套主题都用同一张黑胶盘，靠 accent 中心标签区分。
