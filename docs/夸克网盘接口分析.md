## 1. 域名与通用约定

### 1.1 域名分工（取自 4.6.7 前端 `cloudDriveConfig`）

| 配置项 | 值 | 用途 |
|---|---|---|
| `cloudDriveHost` | `https://drive-pc.quark.cn` | **主域**，本文件 99% 的接口都在这里 |
| `memberCloudDriveHost` | `https://drive-member-h.quark.cn` | 会员/权益相关 |
| `shareCloudDriveHost` | `https://drive-h.quark.cn` | 分享（访客态） |
| `albumCloudDriveHost` | `https://api-album.quark.cn` | 相册/图片 |
| `paramInfo` | `pr=ucpro`、`fr=pc`、`uc_param_str=<可选>` | 公共查询参数 |

> 实测：从 `pan.quark.cn` 页面直接对 `https://drive-pc.quark.cn/...` 发 `fetch(..., {credentials:'include'})` 即可成功（浏览器自动带 Cookie，CORS 已允许 `pan.quark.cn` 源）。客户端（WebView / 原生 HTTP）复用时，**把登录 Cookie（含 `__pus`、`__puus` 等）带上即可**，无需额外 token。

### 1.2 统一响应信封

所有接口返回同一层 JSON 信封：

```json
{
  "status": 200,
  "code": 0,
  "message": "",
  "timestamp": 1794227172,
  "data": { }
}
```

- **成功判据**：`code === 0`（`status` 通常 200）。
- **业务失败**：HTTP 可能仍是 400/200，但 `code` 非 0，`message` 给原因。例：视频转码中 `code=21002 message="video is transcoding [转码中]"`；非视频 `code=21004 message="bad video"`；分辨率非法 `code=21111`；文档不支持预览 `code=26001`；参数错 `code=14001`。
- 列表分页字段在 `data.list`，总数在 `data.metadata._total`（`_fetch_total=1` 时返回）。

### 1.3 公共请求头 / 参数

- 写操作（POST）统一 `Content-Type: application/json`，body 用 JSON。
- 查询串统一追加 `pr=ucpro&fr=pc`（前端还会拼 `uc_param_str`，实测不带也成功）。
- 特殊头 `X-U-Drive-Secret-Auth`：**仅在分享访客态**（URL 带 `secretAuthToken`）时前端才加，正常登录态不需要（源码 `Ie()`）。
- 无 `Referer`/`Origin` 校验也可（浏览器会自动带；原生请求不强制）。

### 1.4 ID 模型（务必分清）

| 名称 | 含义 | 形态 | 备注 |
|---|---|---|---|
| `fid` | 文件 / 文件夹的**唯一 ID**（二者共用同一套 ID） | 32 位十六进制 | 目录也有 fid，和文件一样 |
| `pdir_fid` | **父目录** fid | 同上，根目录固定 `"0"` | 列目录传要展开的目录 fid |
| `obj_key` | 对象存储键（下载/内部用） | 字符串 | 出现在下载/播放返回里 |
| `series_dir`/`album_dir` | 是否相册/剧集目录 | bool | 可忽略 |

> 与百度对比：百度是 `fs_id + path + gid + msg_id + from_uk` 五件套；夸克**只需 `fid` + `pdir_fid`**，没有 IM 消息维度，简单很多。

## 2. 文件管理（列表 / 分类 / 搜索 / 增删改移动）

### 2.1 目录列表 `GET /1/clouddrive/file/sort`  ✅R

**Query 参数**：

| 参数 | 必填 | 说明 |
|---|---|---|
| `pdir_fid` | ✅ | 要列出的目录 fid，根 `"0"` |
| `_page` | ✅ | 页码，从 1 开始 |
| `_size` | ✅ | 每页条数（实测 20/50/100 均可） |
| `_fetch_total` | | `1` 返回总数 |
| `_fetch_sub_dirs` | | `0/1` 是否带子目录 |
| `_sort` | | 排序，逗号分隔，如 `file_type:asc,file_name:asc`（见 2.6） |
| `fetch_all_file` | | 建议 `1` |
| `fetch_risk_file_name` | | 建议 `1` |
| `pr` / `fr` | ✅ | `ucpro` / `pc` |

**实测请求**：

```
GET https://drive-pc.quark.cn/1/clouddrive/file/sort?pr=ucpro&fr=pc&pdir_fid=0&_page=1&_size=20&_fetch_total=1&_fetch_sub_dirs=0&fetch_all_file=1
Cookie: <登录态>
```

**实测响应（截断）**：

```json
{"status":200,"code":0,"message":"","timestamp":1794227172,
 "data":{
   "last_view_list":[],"recent_file_list":[],
   "list":[
     {"fid":"ed338d9a53ac44fab8ea445ef3c57632","file_name":"来自：Qoder","pdir_fid":"0",
      "category":0,"file_type":0,"size":0,"format_type":"","status":1,"tags":"0",
      "l_created_at":1794091326426,"l_updated_at":1794091326426,
      "source":"ucpro-third","file_source":"UCPRO-THIRD:UPLOAD","include_items":2,
      "dir":true,"file":false,"thumbnail":"","md5":""}
     /* ... 普通文件时会带 size / format_type / md5 / thumbnail / duration ... */
   ],
   "metadata":{"_total":22,"_page":1,"_size":20,"_count":20}
 }}
```

**字段要点**：
- `dir:true/file:false` 区分目录；`format_type` 给 MIME（如 `video/mp4`、`application/pdf`）。
- `category`：0=目录/未知、1=视频、2=音频?（实测音频也归 1 视频类 MIME）、4=文本、6=压缩/二进制……以 `format_type` 为准更稳。
- 音视频会带 `duration`、`video_width/height`、`thumbnail`。

### 2.2 分类列表 `GET /1/clouddrive/file/category`  ✅R

**参数**：

| 参数 | 说明 |
|---|---|
| `cat` | `video` / `document` / `audio` / `image` / `bt` / `package`；`all` 传空串 |
| `_page`、`_size`、`_fetch_total` | 分页/总数 |
| `_sort` | 排序 |
| `file_ext` | 可选，按扩展名过滤（如 `pdf`；**实测传 pdf 返回空，未进一步验证排序**） |
| `file_type` | 可选数字 |
| `labels` | 可选，如 `SAVE_AS_TOP_LAYER` |
| `pr`/`fr` | 必带 |

**实测**（`cat=video`）：

```json
{"status":200,"code":0,
 "data":{"list":[
   {"fid":"51ddd2e68f0a42b4a1b0ddf3540e8d8f","file_name":"VID_20261108_114902.mp4",
    "format_type":"video/mp4","category":1,"file_type":1,"size":19424201,"dir":false},
   {"fid":"02d2d57b856c425e8007e0d6040c9af4","file_name":"wx_camera_1794116088279.mp4",
    "format_type":"video/mp4","category":1,"file_type":1,"size":1456407,"dir":false}
 ]}}
```

> 「全部 / 视频 / 音频 / 文档」筛选页直接用这个接口，**比遍历目录再按扩展名过滤快**，适合做 Baidu 版的「全部/音频/视频/文档」过滤器。

### 2.3 搜索 `GET /1/clouddrive/file/search`  ✅R

**参数**：`q`（关键词）、`_page`、`_size`、`_fetch_total=1`、`_sort`、`_is_hl=1`、`pr`、`fr`。

**实测响应** `data.list[]` 结构与 `file/sort` 相同（含 `dir`、`format_type`、`size`）。搜索会同时命中目录与文件，需按 `dir` / `format_type` 自行过滤。

### 2.4 新建文件夹 `POST /1/clouddrive/file`  ✅R

**Body（JSON）**：

```json
{"pdir_fid":"0","file_name":"新文件夹","dir_path":"","dir_init_lock":false}
```

| 字段 | 说明 |
|---|---|
| `pdir_fid` | 父目录 fid，根 `"0"` |
| `file_name` | 新目录名 |
| `dir_path` | 通常空串 |
| `dir_init_lock` | 默认 `false`；上传时前端有用 `true` 先占位目录 |

**实测响应**：

```json
{"status":200,"code":0,"data":{"finish":true,"fid":"7e536abd5ec84a3f96d4aaad2c9e3544"}}
```

> 返回 `data.fid` 即新目录 ID，`data.finish=true` 表示同步完成。

### 2.5 重命名 `POST /1/clouddrive/file/rename`  ✅R

**Body**：

```json
{"fid":"4a1a0140532948cf8c019400ed317ca2","file_name":"新名字.mp4"}
```

**实测响应**：`{"status":200,"code":0,"data":{}}`（成功即 `code=0`，`data` 空对象）。

### 2.6 移动 `POST /1/clouddrive/file/move`  ✅R

**Body**：

```json
{"action_type":1,"to_pdir_fid":"7e536abd5ec84a3f96d4aaad2c9e3544","filelist":["4a1a0140532948cf8c019400ed317ca2"],"exclude_fids":[]}
```

| 字段 | 说明 |
|---|---|
| `action_type` | `1`=SYNC（同步等待结果）、`2`=ASYNC（返回异步任务） |
| `to_pdir_fid` | 目标目录 fid |
| `filelist` | 要移动的 fid 数组（**注意是数组，不是对象**） |
| `exclude_fids` | 排除的子 fid，一般 `[]` |

**实测响应**（`action_type=1`）：`{"status":200,"code":0,"data":{"task_id":"ce2f...","finish":true}}`

> 批量移动：把多个 fid 放进 `filelist` 一次提交即可。

### 2.7 删除 `POST /1/clouddrive/file/delete`  ✅R

**Body**：

```json
{"action_type":2,"filelist":["4a1a0140532948cf8c019400ed317ca2"],"exclude_fids":[]}
```

**实测响应**：`{"status":200,"code":0,"data":{"task_id":"0b5f...","finish":false}}`
- `action_type=2`（ASYNC）返回 `task_id`、`finish=false`（后台任务），可轮询 `GET /1/clouddrive/task` 查进度。
- 需「删完立刻反映」可用 `action_type=1`（SYNC）等待。

> 删除目录会**级联删除其内容**（实测：把子目录移进父目录后删父目录即可连带清掉）。

### 2.8 文件信息 / 完整路径

- `GET /1/clouddrive/file/info?fid=<fid>&_fetch_full_path=1&need_profile_tags=1` → `data` 单文件详情（含 `full_path`）。
- `POST /1/clouddrive/file/info/path_list`，**Body 实测只认 `fids` 数组**：`{"fids":["<fid1>","<fid2>"]}`（传 `path_list` 会报 `14001 Bad Parameter: [fids is empty!]`）。返回每个 fid 的完整路径数组，适合「详情 / 定位」。

## 3. 视频 / 音频 取址

### 3.1 视频播放取址 `POST /1/clouddrive/file/v2/play`  ✅R

**Body**：

```json
{"fid":"51ddd2e68f0a42b4a1b0ddf3540e8d8f",
 "resolutions":"normal,low,high,super,2k,4k",
 "supports":"fmp4,m3u8"}
```

| 字段 | 说明 |
|---|---|
| `fid` | 视频文件 fid |
| `resolutions` | **逗号分隔**的候选清晰度集合，合法值取自前端：`normal,low,high,super,2k,4k`；缺省前端传 `low` |
| `supports` | 固定 `fmp4,m3u8` |

**实测响应（精简）**：

```json
{"status":200,"code":0,"message":"ok",
 "data":{
   "default_resolution":"high","origin_default_resolution":"high",
   "video_list":[{
     "resolution":"high",
     "video_info":{
       "duration":10,"size":19424201,"format":"mov,mp4,m4a","width":1280,"height":720,
       "bitrate":14860,"codec":"h264","fps":30.03,"rotate":90,
       "audio":{"codec":"aac","channels":2,"bitrate":256.479},
       "url":"https://video-play-c-sz.drive.quark.cn/…{auth_key/token/ork 签名}…",
       "hls_type":"none","finish":true,"success":true
     },
     "right":"svip","member_right":"svip","trans_status":"raw","accessable":true
   }],
   "audio_list":[],
   "file_name":"VID_20261108_114902.mp4","size":19424201,
   "thumbnail":"https://drive-pc.quark.cn/1/clouddrive/file/video/thumbnail?fid=…",
   "meta":{"duration":10,"width":1280,"height":720,"codec":"h264"},
   "preload_level":3,"has_seek_preview_data":false
 }}
```

**关键点**：
- **可播地址 = `data.video_list[].video_info.url`**。当 `hls_type:"none"` 时可按渐进式媒体读取，返回 `m3u8` 时按 HLS 播放。
- `video_info.url` 是带签名的 CDN 地址。App 实测中，播放器未带登录会话时收到 HTTP 412，按请求目标域读取夸克登录 Cookie 后可以播放。签名地址与 Cookie 均不写入播放记录。
- `right / member_right`：权益标识（如 `svip`）。高清晰度可能受 SVIP 限制；返回里给的 `url` 已按当前账号权益签发。
- **常见业务码**：
  - `21002 video is transcoding` → 视频还在转码，稍后重试（前端会轮询）。
  - `21111 video query resolution invalid` → `resolutions` 传了不支持的值（务必用合法集合）。
  - `21004 bad video` → 不是视频（音频走此接口会报错，见 3.2）。

### 3.2 音频播放 / 原始文件直链 `POST /1/clouddrive/file/download`  ✅R

> **音频不能走 `file/v2/play`**（实测 `code=21004 bad video`）。夸克网页版对音频、以及「下载原文件」，统一走 `file/download` 拿 **`download_url`** 直链来播放/下载。

**Body**：

```json
{"fids":["e5315467008a4409b09a22338dd8eacd"]}
```

（可选带分享态参数 `pwd_id`、`stoken`、`fids_token`，个人网盘不需要。）

**实测响应（单个视频文件，节选字段）**：

```json
{"status":200,"code":0,
 "data":[{
   "fid":"51ddd2e68f0a42b4a1b0ddf3540e8d8f","file_name":"VID_20261108_114902.mp4",
   "size":19424201,"format_type":"video/mp4","md5":"385d831a7cf37c85fb5e8dea3b68b673",
   "obj_key":"e79075f6f3b14ff6832c6b3a04b34a3f",
   "download_url":"https://dl-pc-sz.pds.quark.cn/…{OSS 签名}&Expires=1794248837…",
   "preview_url":"https://drive-pc.quark.cn/1/clouddrive/file/video/preview?fid=…",
   "thumbnail":"https://drive-pc.quark.cn/1/clouddrive/file/video/thumbnail?fid=…",
   "big_thumbnail":"https://drive-pc.quark.cn/1/clouddrive/file/video/quick?fid=…",
   "video_max_resolution":"high","video_width":1280,"video_height":720,"duration":10
 }]}
```

**关键点**：
- **原文件直链 = `data[].download_url`**（阿里 OSS 预签名，`Expires` 约 8 小时，带 `response-content-disposition` 指定文件名）。
- **音频（mp3/m4a/aac/flac/wav…）就用这个 `download_url` 直接喂播放器**，无需转码；也可用 `file/v2/play`? 不行（会 `21004`）。
- `data` 是**数组**，批量传多个 fid 会一次返回多条。

### 3.3 取址决策表（视频 / 音频 / 文档）

```
判断 entry（看 format_type / 扩展名 / dir）：
  目录(dir=true)                       → 不取址，进入下钻（file/sort pdir_fid=fid）
  视频(mp4/mkv/mov/avi/flv/wmv/webm/ts/m4v/3gp…)
        在线播放 → POST file/v2/play {fid,resolutions:"normal,low,high,super,2k,4k",supports:"fmp4,m3u8"}
                  取 data.video_list[].video_info.url（hls_type=none→mp4；有 m3u8→HLS）
        原始下载 → POST file/download {fids:[fid]} → data[].download_url
  音频(mp3/m4a/aac/flac/wav/wma/ogg/m4b/amr…)
        播放/下载 → 直接 POST file/download → data[].download_url（不要用 v2/play）
  PDF(application/pdf)
        预览 → POST pdf/preview {fid} → data.page_imgs[] 逐页图片 + data.download_url
  Office(doc/docx/xls/xlsx/ppt/pptx/wps/csv/rtf…)
        预览 → POST doc/previewnew {fid} → data.preview_info.preview_url（阿里云 Office 在线）
        （如需落地文件→ file/download 拿 download_url；格式转换→ doc/convert）
  纯文本(txt/md/log/json…)
        预览 → POST rich_text/preview {fid} → data.download_url
  其他未知
        原文件 → POST file/download → data[].download_url
```

> 对比百度：百度是 `streaming`（音视频 HLS 转码）＋`sharedownload`（dlink）；夸克是 `file/v2/play`（视频）＋`file/download`（音频/原文件 dlink）＋ `pdf/preview`/`doc/previewnew`/`rich_text/preview`（文档）。夸克**没有**「音视频统一转码接口」，音频直接下原文件播。

### 4.1 PDF 逐页预览 `POST /1/clouddrive/pdf/preview`  ✅R

**Body**：`{"fid":"67a179e572a34b32b4371314a3587bcb"}`

**实测响应（精简）**：

```json
{"status":200,"code":0,"message":"ok",
 "data":{
   "download_url":"https://dl-c-sz-u.drive.quark.cn/…{签名}…","size":244541,
   "sha1":"7974c2e8…","sham":"2b7f61d8…",
   "page_imgs":[
     {"page":1,"page_width":595,"page_height":842,
      "img_urls":["https://dl-c-sz-u.drive.quark.cn/…{第1页图片签名}…"]},
     {"page":2,"page_width":595,"page_height":842,"img_urls":["…"]},
     {"page":3,"page_width":595,"page_height":842,"img_urls":["…"]}
   ],
   "extract_info":{"pdf":{"is_linearized":0,"xref_offsets":[…],"has_unknown_chars":0}},
   "progress_info":{},"draft_info":{}
```

### 5.1 创建分享 `POST /1/clouddrive/share`

**Body**（源码 4.6.7）：

### 5.2 上传四步（源码契约）

| 步骤 | 接口 | Body 关键字段 |
|---|---|---|
| 1 预判 | `POST /1/clouddrive/file/upload/pre` | `{pdir_fid, dir_name, file_name, size, format_type, l_updated_at, l_created_at, parallel_upload, ccp_hash_update, md5?, sha1?}` |

## 6. 与「百度网盘所需接口」对照（迁移参考）

> 下表把本仓库 `PanApi.kt` / `docs/网盘文件管理-实施方案.md` / `docs/媒体取址技术方案.md` 里用到的百度接口，逐一映射到夸克等价接口。

| 能力 | 百度（现有） | 夸克（等价） | 差异备注 |
|---|---|---|---|
| 目录列表 | `GET /api/list` | `GET /1/clouddrive/file/sort` | 参数全变：`pdir_fid/_page/_size`；返回 `data.list[]` |
| 分类筛选 | 无（前端过滤） | `GET /1/clouddrive/file/category` | 夸克原生支持 video/document/audio/image |
| 搜索 | `GET /api/search` | `GET /1/clouddrive/file/search` | `q` 关键词 |
| 视频播放 | `GET /mbox/msg/streaming?type=M3U8_AUTO_480` | `POST /1/clouddrive/file/v2/play` | 夸克返回 `video_info.url`（mp4 或 m3u8） |
| 音频播放 | `GET /mbox/msg/streaming?type=M3U8_MP3_128` | `POST /1/clouddrive/file/download`→`download_url` | 夸克音频不转码，直接下原文件 |
| 文档下载/直链 | `GET /api/sharedownload`→`dlink` | `POST /1/clouddrive/file/download`→`download_url` | 都是 OSS/CDN 预签名直链 |
| PDF 取址 | `GET /rest/2.0/docview/dlink` | `POST /1/clouddrive/pdf/preview` | 夸克直接给逐页图片，更省事 |
| Office 预览 | `docview` | `POST /1/clouddrive/doc/previewnew` | 夸克返回阿里 Office 在线 URL |
| 新建文件夹 | `POST /api/create`（isdir=1） | `POST /1/clouddrive/file` | 夸克 `{pdir_fid,file_name}` |
| 重命名 | `POST /api/filemanager`（opera=rename） | `POST /1/clouddrive/file/rename` | 夸克独立端点 `{fid,file_name}` |
| 移动 | `POST /api/filemanager`（opera=move） | `POST /1/clouddrive/file/move` | `{action_type,to_pdir_fid,filelist[]}` |
| 复制 | `POST /api/filemanager`（opera=copy） | **无独立端点**（web 包内未发现 file/copy） | 夸克网页版无「复制」，可考虑「移动/重传」替代（U） |
| 删除 | `POST /api/filemanager`（opera=delete） | `POST /1/clouddrive/file/delete` | `{action_type:2,filelist[]}` |
| 分享 | `POST /share/set` | `POST /1/clouddrive/share` | 夸克 `{fid_list,title,url_type,passcode,expired_type}` |
| 转存 | `POST /api/transfer` | `POST /1/clouddrive/share/sharepage/save` | 夸克分享转存走 sharepage/save（未实测） |
| 上传预判/分片/收尾 | `/api/create`(rtype) + `/rest/2.0/pcs/superfile2` | `upload/pre`→`upload/auth`→`upload/partinfo`→`upload/finish` | 夸克分片走 OSS |
| 账号/Token | `gettemplatevariable`（uk/bdstoken） | **无**（仅 Cookie） | 夸克无需 bdstoken/sign |
| 鉴权 | Cookie + bdstoken + 同源 | **仅 Cookie**（跨域 CORS 放行） | 夸克更简单 |

**迁移要点**：
1. **去掉 `bdstoken`/`sign` 这一层**：`PanApi` 里所有 `ensureBdstoken()`、`api()` 拼 `app_id/channel` 等百度专有参数全部删除，换成夸克的 `pr=ucpro&fr=pc`。
2. **ID 从「fsid + path」改为「fid + pdir_fid」**：`CourseCache` 的目录 key 从 `disk:dir:<fsid>` 用 fid 即可；不再需要拼 `/a/b` 路径串。
3. **写操作从「filemanager 单端点 + opera」拆成独立端点**：`rename/move/delete` 各一个 URL，改写更清晰。
4. **播放取址拆两路**：视频走 `v2/play`，音频/原文件走 `download`。`VideoStreamResolver` 里 ExoPlayer 可直接吃 `video_info.url`（mp4）或 m3u8。
5. **PDF 阅读**可直接用 `pdf/preview` 的 `page_imgs` 逐页图片渲染，省掉下载到本地再用 PDF 引擎的方案（`PdfFileFetcher` 可简化）。

## 8. 错误码（实测 / 源码）

| code | 含义 | 场景 |

## 9. 实测方法与复现（可自行重跑）

1. Edge 开启「开发 > 允许 Apple 事件中的 JavaScript」，用 AppleScript 对 `pan.quark.cn` 标签页执行 JS：

## 10. 风险与未验证项（U）

1. **纯 Cookie 鉴权**：夸克只认 Cookie，无 `sign`。Cookie 一旦过期（`__puus` 等），所有接口 `code≠0`；需要复用登录 WebView 的 Cookie，或做「登录态失效」检测与重登。
2. **签名直链时效**：`video_info.url` 有效期约 3h、`download_url` 约 8h，且 `auth_key/token` 内含账号信息；**一次性使用、别持久化**（与现有 `MediaAddressCache` 6h TTL 思路一致即可）。
3. **SVIP 权益**：`video_list[].right/member_right` 会体现会员态；高清晰度/部分能力可能受权益限制，返回的 `url` 已按当前账号签发，但换账号需重取。
4. **复制能力缺失**：web 包中未发现 `file/copy`，夸克网页版似乎**没有复制**；若产品需要，只能用「移动/重新上传」变通（待真机确认是否有其它端点，U）。
5. **分享/上传为源码契约（S）**：`/share`、`upload/*` 未端到端点通，字段可能随前端发版微调；集中封装在一处便于单点修正。
6. **`resolutions` 集合**：合法值取自前端源码 `normal,low,high,super,2k,4k`；实测 `low` 单传对「原始未转码 mp4」会报 `21111`，传全集正常。建议**始终传全集**让服务端选 `default_resolution`。
7. **音频归类**：音频文件 MIME 常是 `video/mp4`（m4a），`format_type` 未必是 `audio/*`；判断「音频」建议按扩展名（mp3/m4a/aac/flac/wav…），别只看 category。
8. **分页**：`_size` 过大可能被服务端截断，建议 ≤ 100/页；总数据 `metadata._total`。
