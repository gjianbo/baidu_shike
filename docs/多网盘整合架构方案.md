> 版本：v0.1　生成日期：2026-11-09

## 0. 结论

把应用做成 **"领域模型(CloudRef) + 能力声明(CloudProvider) + 仓储(CloudRepository) + 通用 UI 组件"** 四件套，即可把百度、夸克以及未来的网盘统一到一个应用下，全部走 Web 接口。

- **通用内核 = "个人盘浏览器"**（列表 / 搜索 / 分类 / 取址 / 预览 / 新建·重命名·移动·删除·分享·上传）。
- **"群组文件库 / 转存" = 百度专属的扩展能力**（`Cap.GROUP_LIBRARY`），不进通用层。
- 播放与文档用 **密封类** 吃掉两家形态差异（百度 m3u8 / 夸克 mp4；百度 dlink / 夸克逐页图 / 阿里 Office）。
- 改造顺序 **P0→P4**，每期可独立发版、可回滚；先"包住百度零回归"，再"接夸克验证"，最后"拆 6k 行 Activity"。

## 1. 目标与边界

### 1.1 做

1. 一个 App 同时登录 / 切换 **百度网盘** 与 **夸克网盘**（各自独立登录态）。
2. 统一下列能力（两家都有的）：目录浏览、搜索、分类、视频/音频播放、原文件下载、PDF/Office/文本预览、新建文件夹、重命名、移动、删除、分享、上传。
3. 收藏 / 最近播放 / 播放进度 / 目录缓存 **跨网盘统一管理**（按 provider+账号隔离）。
4. 预留第三个 provider 的接入点，新增一个网盘只写一个 `CloudProvider` 实现。

### 1.2 不做 / 边界

- **不做**"把百度的群组文件库强行搬到夸克"——夸克个人盘没有对等的群组/消息模型；群组能力只属于百度 Provider。
- **不做**跨网盘搬家式同步（百度转夸克批量迁移）本期不碰，仅做"各自管理 + 统一浏览"。
- **不动**现有播放器内核（ExoPlayer / Media3）、主题、备份框架——它们本来就与 provider 无关（耦合 hit=0）。

## 2. 现状体检（S）

### 2.1 耦合分布（`app/src/main/java/com/hnwd/bdplayer`）

| 文件 | 行数 | 百度专有 hit | 角色 |
|---|---|---|---|
| `PanApi.kt` | 574 | **87** | 所有接口占位/参数/解析，百度专有 |
| `MainActivity.kt` | **6389** | **88** | God-Activity，UI+编排+请求全在一起 |
| `CourseCache.kt` | 187 | 6 | 目录分页缓存（key 含 gid/msg） |
| `AudioHistory.kt` | 119 | 4 | 最近播放/进度（key 含 origin/gid/msg/file） |
| `Favorites.kt` | 85 | 3 | 收藏（JSON 硬编码 gid/message/owner） |
| `PdfFileFetcher.kt` | 176 | 3 | PDF 下载缓存（百度 dlink） |
| `VideoStreamResolver.kt` | 118 | 2 | m3u8 拉取+校验（百度专有错误码） |
| `MediaAddressCache.kt` | 72 | 1 | m3u8/直链缓存（host 校验百度） |
| `AccountScope.kt` | 68 | 0 | 账号分桶（只按百度 uk） |
| 其余（播放/主题/备份/布局…） | — | **0** | provider 无关 |

**结论**：耦合高度集中在 `PanApi` + `MainActivity`；播放器/主题/备份天然干净，不需要动。

### 2.2 UI 已天然分两条流（关键利好）

- **disk 流（我的网盘，要抽象的通用核心）**：`refreshDisk` / `loadDiskPage` / `renderDiskMore` / `searchDiskFiles` / `loadMoreDiskCourses` / `currentDiskDir` / `runDiskWrite` / `afterDiskMutation` / `promptNewFolder` / `promptRename` / `promptMoveCopy`。
- **group 流（群组文件库，百度专属扩展）**：`refresh` / `loadRoots` / `loadChildren` / `searchFiles` / `openFolderTrail` / `renderRootMore` / `renderChildMore`。

> 抽象时**只把 disk 流提到通用层**；group 流留在 `BaiduProvider` 的扩展命名空间里。这是本方案能"通用"的前提。

### 2.3 现有模型的百度烙印（S）

- `PanEntry` 字段 `gid / messageId / owner / fileId / path / origin: {GROUP, DISK}` —— 强百度语义（群组消息维度）。
- 身份/相等判断到处用 `origin + gid + messageId + fileId`（`Favorites.same`、`AudioHistory.sameFile`、`CourseCache.idOf`、`mediaCacheKey`）。
- 夸克只有 `fid / pdir_fid / path`，无 gid/msg/owner。

> 因此模型层必须重做，用 `provider + account + fileId` 作为稳定身份，provider 专有 ID 收进 `extra` 字典。

## 4. P0 骨架代码（设计与示意，不要求一次性落地）

> 下面的 Kotlin 为**接口契约草案**，用于统一各方认知；真实实现时可微调包名/可见性。目标：把 `PanApi` 原样包进 `BaiduProvider`，对外行为零变化。

### 4.1 领域模型

```kotlin
enum class Provider(val id: String) { BAIDU("baidu"), QUARK("quark") }
enum class Scope { PERSONAL, GROUP }              // GROUP 仅百度群组
enum class MediaKind { VIDEO, AUDIO, PDF, OFFICE, TEXT, DOCUMENT, DIRECTORY, OTHER }

/** 与网盘厂商无关的统一节点。 */
data class CloudRef(
    val provider: Provider,
    val accountId: String,        // 百度 uk / 夸克 uid
    val scope: Scope = Scope.PERSONAL,
    val fileId: String,           // 百度 fs_id / 夸克 fid
    val parentId: String,         // 夸克 pdir_fid；百度空或由 path 推导
    val path: String,             // 绝对路径（面包屑/定位用）
    val name: String,
    val size: Long,
    val dir: Boolean,
    val kind: MediaKind,
    val md5: String = "",
    val extra: Map<String, String> = emptyMap(),  // 厂商专有：baidu{gid,messageId,owner} / quark{obj_key}
) {
    val key: String get() = "${provider.id}|$accountId|$fileId"
}

data class Page<T>(val items: List<T>, val next: String?, val total: Long? = null)
enum class Category { ALL, VIDEO, AUDIO, DOCUMENT, IMAGE, PACKAGE }
```

### 4.2 能力声明 + 能力矩阵

enum class Cap {

### 4.3 结果密封类（吃掉形态差异）

```kotlin
sealed class Playback {
    data class Hls(val url: String) : Playback()           // 百度 m3u8 / 夸克转码 m3u8
    data class Progressive(val url: String) : Playback()   // 夸克原始 mp4 / 音频原文件
}

sealed class Preview {
    data class Pages(val urls: List<String>, val width: Int, val height: Int) : Preview() // 夸克 pdf
    data class Office(val url: String, val token: String?) : Preview()                     // 夸克 doc
    data class PdfFile(val url: String) : Preview()                                        // 百度 docview dlink
    data class RawUrl(val url: String) : Preview()                                         // 文本/兜底
}

sealed class CloudError(message: String) : Exception(message) {
    class AuthExpired : CloudError("登录态失效")
    class Auth(msg: String) : CloudError(msg)
    class Transcoding : CloudError("转码中")        // 夸克 21002 / 百度 31341
    class NotSupported(val cap: Cap) : CloudError("该网盘不支持 ${cap}")
    class Quota : CloudError("空间不足")
    class RateLimited : CloudError("触发风控")
    class Network : CloudError("网络错误")
    class Unknown(val code: Int, val detail: String) : CloudError("[$code] $detail")
}
```

### 4.4 CloudProvider SPI

```kotlin
interface CloudProvider {
    val id: Provider
    fun supports(cap: Cap): Boolean

    suspend fun login(host: Any): Boolean                 // 打开对应域名登录 WebView
    suspend fun currentAccount(): String?                 // uk / uid
    suspend fun isLoggedIn(): Boolean

    // 浏览
    suspend fun list(parent: CloudRef?, page: Int, pageSize: Int, sort: String? = null): Page<CloudRef>
    suspend fun search(query: String, page: Int, pageSize: Int): Page<CloudRef>
    suspend fun category(cat: Category, page: Int, pageSize: Int): Page<CloudRef> =
        throw CloudError.NotSupported(Cap.CATEGORY)

    // 取址
    suspend fun resolveVideo(ref: CloudRef): Playback
    suspend fun resolveAudio(ref: CloudRef): Playback
    suspend fun downloadUrl(ref: CloudRef): String
    suspend fun preview(ref: CloudRef): Preview

    // 写
    suspend fun createFolder(parent: CloudRef, name: String): CloudRef
    suspend fun rename(ref: CloudRef, newName: String): Unit
    suspend fun move(refs: List<CloudRef>, dest: CloudRef): Unit
    suspend fun copy(refs: List<CloudRef>, dest: CloudRef): Unit =
        throw CloudError.NotSupported(Cap.COPY)
    suspend fun delete(refs: List<CloudRef>): Unit

    // 分享 / 转存 / 上传（可选）
    suspend fun share(refs: List<CloudRef>, opt: ShareOpt): ShareResult
    suspend fun transferIn(src: CloudRef, dest: CloudRef): Unit =
        throw CloudError.NotSupported(Cap.TRANSFER_IN)
    suspend fun upload(localPath: String, parent: CloudRef, progress: (Float) -> Unit): CloudRef =
        throw CloudError.NotSupported(Cap.UPLOAD)

    // 群组（仅百度实现）
    suspend fun groups(): List<GroupRef> = throw CloudError.NotSupported(Cap.GROUP_LIBRARY)
    suspend fun listGroup(group: GroupRef, parent: CloudRef?, page: Int): Page<CloudRef> =
        throw CloudError.NotSupported(Cap.GROUP_LIBRARY)
}
internal data class ShareOpt(val periodDays: Int, val passcode: String = "")
internal data class ShareResult(val link: String, val passcode: String)
internal data class GroupRef(val id: String, val name: String, val meta: Map<String, String> = emptyMap())
```

### 4.5 CloudRepository / SourceRegistry / WebTransport

```kotlin
interface WebTransport {            // 一个 provider 一个隐藏 WebView + 各自 Cookie 域
    suspend fun requestJson(method: String, pathWithQuery: String, body: String? = null): String
    suspend fun loadLogin(url: String): Boolean
    suspend fun account(): String?
}

class CloudRepository(providers: Map<Provider, CloudProvider>) {
    private val map = providers
    fun of(p: Provider): CloudProvider = map.getValue(p)
    // UI 只调这里；内部按 ref.provider 路由，做会话校验、缓存读写、错误归一化
    suspend fun list(ref: CloudRef?, page: Int, pageSize: Int): Page<CloudRef> =
        of(ref?.provider ?: error("provider required")).list(ref, page, pageSize)
    // ...
}
```

> 传输层要点：百度必须跑在 `pan.baidu.com` 同源页执行 JS；夸克在 `pan.quark.cn` 页面对 `drive-pc.quark.cn` 跨域（CORS 已放行）。**一个 provider 一个隐藏 WebView**，Cookie 天然按域隔离；`load()+轮询` 的既有机制两边通用。

## 5. 管理层改造 + 数据迁移（provider 无关）

### 5.1 统一主键

| 存储 | 现状 key | 目标 key |
|---|---|---|
| AccountScope | `acct_<uk>__<mod>` | `acct_<provider>_<account>__<mod>` |
| Favorites | `acct_<uk>__favorites` | `acct_<provider>_<account>__favorites` |
| AudioHistory | `acct_<uk>__<bucket>`（bucket=gid/disk） | `acct_<provider>_<account>__<bucket>` |
| CourseCache | `acct_<uk>__<dirkey>:<page>` | `acct_<provider>_<account>__<dirkey>:<page>` |
| MediaAddressCache | 哈希含 origin/gid/msg/owner/file | 哈希含 `provider/account/fileId` |

条目身份统一为 `CloudRef.key = provider|account|fileId`。

### 5.2 迁移脚本（必须做，否则老用户数据丢失）

- 应用启动时一次性检测旧 key（`acct_<纯数字uk>__*`），把无前缀的记录复制到 `acct_baidu_<uk>__*`，写迁移标记 `migrated_multi_v1=true`。
- 迁移只"复制 + 标记"，**不删旧数据**（保留一个版本以便回滚）。
- `Favorites/AudioHistory/CourseCache` 的 JSON 结构保留，但读取时补 `provider=BAIDU`、`accountId=uk`，`fileId` 沿用 `fs_id`。

## 7. 抽象漏点与处置（10 条）

| # | 差异 | 百度 | 夸克 | 处置 |
|---|---|---|---|---|
| 1 | 鉴权 | Cookie + bdstoken + 同源 | 仅 Cookie（对 drive-pc 跨域 CORS） | Session 按 provider 隔离；`WebTransport` 各自域名 |
| 2 | ID | fs_id + path + gid + msg_id + owner | fid + pdir_fid + path | `CloudRef.extra` 收专有 ID |
| 3 | 分页 | page / last_msg_time 游标 | _page/_size | `Page.next` 统一游标 |
| 4 | 播放 | streaming 返回 m3u8 再校验 `#EXTM3U` | v2/play 直给签名 mp4/m3u8；音频走 download | `Playback` 密封类 |
| 5 | 文档 | docview→dlink 下载渲染 | pdf 逐页图 / office 阿里 URL / text dlink | `Preview` 密封类 |
| 6 | 写 | filemanager 单端点 + opera | rename/move/delete 三端点；无 copy | 方法拆分 + `supports(COPY)` |
| 7 | 错误 | -20 风控/验证码、31304/31341 | 21002/21004/26001/14001 | 归一到 `CloudError` |
| 8 | 权益 | is_vip、sign1..3 | right/member_right | 统一 `Right`，取址透传 |
| 9 | 群组 | 核心业务（gid/msg_id/转存） | 无对等 | 降级为 `Cap.GROUP_LIBRARY` 百度专属 |
| 10 | 缓存/去重 | md5 第 10 位混淆、`*.baidupcs.com` | md5 正常、`dl-*.quark.cn` | 指纹/host 校验下沉到各 Provider |

## 8. 落地路线（文件级清单，可分期回滚）

### P0 打地基（不改行为，百度零回归）
- 新增包 `core/`：`Provider.kt`、`Cap.kt`、`CloudRef.kt`、`Page.kt`、`Playback.kt`、`Preview.kt`、`CloudError.kt`、`CloudProvider.kt`、`CloudRepository.kt`、`WebTransport.kt`。
- 新增 `provider/baidu/BaiduProvider.kt`：**内部直接调用现有 `PanApi`**，把 `PanEntry` ↔ `CloudRef` 互转（`extra` 塞 gid/messageId/owner）。
- 现有 UI/仓储不动，先只让 `BaiduProvider` 通过单元测试。
- 验收：既不接夸克也不改 UI，编译通过、现有功能零回归。

### P1 抽仓储（MainActivity 减负）
- 新增 `DiskBrowserRepository`：把 disk 流的 `refreshDisk/loadDiskPage/searchDiskFiles/loadMoreDiskCourses/runDiskWrite` 逻辑搬进来，内部走 `CloudRepository.of(BAIDU)`。
- `MainActivity` 只保留"调仓储 + 渲染"。
- 验收：disk 流功能不变，`MainActivity` 行数下降，`PanApi.*` 直接调用清零（移到 Provider 内）。

### P2 抽 UI
- 提炼 `BrowserScreen / EntryListView / PlayerHost / DocViewerHost / ActionSheet`，吃领域模型。
- 群组页作为 `BaiduProvider` 的独立页面保留。
- 验收：UI 组件单测 + 快照；disk 页与 group 页视觉无变化。

### P3 接夸克
- 新增 `provider/quark/QuarkProvider.kt`（+ `QuarkWebTransport`）：
  - list→`GET /1/clouddrive/file/sort`；search→`/file/search`；category→`/file/category`
  - video→`POST /file/v2/play`（`resolutions:"normal,low,high,super,2k,4k"`,`supports:"fmp4,m3u8"`）
  - audio/download→`POST /file/download`（`fids`）→`download_url`
  - preview：pdf→`/pdf/preview`(Pages)、office→`/doc/previewnew`(Office)、text→`/rich_text/preview`(RawUrl)
  - create→`POST /file`；rename→`/file/rename`；move→`/file/move`(action_type=1)；delete→`/file/delete`(action_type=2)
  - share→`POST /share`；upload→`upload/pre→auth→partinfo→finish`；copy→`NotSupported`
- 注册到 `SourceRegistry`；UI 增加"网盘来源切换"。
- 验收：对照 `docs/夸克网盘接口分析.md` 逐条联调。

### P4 管理数据迁移
- `AccountScope` 改为 provider+account；`Favorites/AudioHistory/CourseCache/MediaAddressCache` 换 `CloudRef.key`。
- 启动迁移 `acct_<uk>__* → acct_baidu_<uk>__*`。
- 验收：老账号收藏/最近/进度迁移后全部可见；新增夸克账号数据互不干扰。

## 11. 缓存 / 去重 / 权益

- **去重指纹**：两家都有 `md5 + size`。"已转存"匹配沿用现有 `PanApi.md5Key`（百度第 10 位混淆）与夸克正常 md5；把算法下沉到 Provider 的 `fingerprint(ref)`。
- **直链缓存 TTL**：百度 m3u8 6h；夸克视频签名≈3h、download≈8h。`MediaAddressCache` TTL 按 provider 配置。
- **权益**：百度 `is_vip`、夸克 `right/member_right`；`CloudRef.extra` 或 `resolveVideo` 返回里带 `Right`，播放器/UI 据此提示"高清需会员"。

## 12. 风险 / 验收 / 回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| 拆 6k 行 `MainActivity` 回归 | 高 | P1/P2 分步，先包 Provider 不改 UI；每步全量回归 |
| 本地数据迁移写错 | 高（老用户数据"消失"） | 只复制不删、迁移标记、灰度、可回滚 |
| 夸克无 copy/无群组被强求对齐 | 中（拖垮通用层） | 明确边界：copy/群组=可选能力，UI 按 supports 隐藏 |
| 百度群组私有接口易变 | 中 | 群组隔离在 BaiduProvider 内，改动不外溢 |
| 双登录态切换 | 中 | 一个 provider 一个 WebView + Cookie 域隔离 |

**验收总纲**：P0 百度零回归；P3 夸克逐条对齐实测契约；P4 老账号数据完整迁移 + 双账号不串。
