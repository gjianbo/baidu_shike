# 拾课 · 功能盘点与扩展规划

- 版本基线：0.1.23（`versionCode 24`，分支 `main`）
- 盘点依据：`app/src/main/java/com/hnwd/bdplayer/*.kt` 源码 + `docs/` 已有技术验证
- 目标：在「网盘 + 群组管理」已落地的基础上，给出下一阶段值得做、能落地、收益高的功能清单与优先级

---

## 二、可扩展功能清单（按优先级）

### P0 · 低成本高收益（建议下一个版本做）

#### 1. 全局搜索（跨群 + 我的网盘）
- **价值**：现在搜索只覆盖「当前群」或「我的网盘」，用户记不住课在哪个群时无解。
- **做法**：并行调用 `shareSources()` 每个 gid 的 `PanApi.searchGroup` + `PanApi.diskSearch`，结果合并去重（`PanApi.md5Key`），带来源标签；复用现有 `dialog_search_results` 与 `locateSearchHit` 定位能力。
- **改动**：`MainActivity.showFileSearch` 增加「全部来源」选项；`searchFiles` 改并发聚合。
- **难度**：S–M。

#### 2. 批量操作（多选收藏 / 下载 / 转存）
- **价值**：整门课几十上百集，逐条点星标、逐条下载效率极低。
- **做法**：目录列表长按进入多选模式，底部批量条：批量收藏、批量加入播放列表、批量离线下载。
- **改动**：`courseRow`/`item_course` 增加选中态；`Favorites.toggle` 扩展为 `addAll`；下载走新模块（见 P0-5）。
- **难度**：M。

#### 3. 睡眠定时 + 播完本目录停止
- **价值**：听课程/音频入睡、通勤场景刚需。
- **做法**：音频/视频播放器加「定时关闭（15/30/60 分钟/本集结束）」；`AudioPlaybackService` 与 `VideoPlaybackPage` 各挂一个计时器，到点 `pause`。
- **难度**：S。

#### 4. 「未听 / 未完成」筛选
- **价值**：课程多时，最需要「继续没听完的」。现有过滤只有媒体类型和「已转存」。
- **做法**：在 `MediaFilter` 旁加一个基于 `audioHistory/videoHistory` 的状态过滤（未开始 / 进行中 / 已完成），复用 `progressMark` 已有数据。
- **难度**：S。

#### 5. 音频离线下载（重点推荐）
- **价值**：地铁/飞机/流量受限时能听；也是「只听声音」场景的自然延伸。当前只有 PDF 会下载，音视频全靠在线。
- **做法**：音频优先——`/api/streaming?type=M3U8_MP3_128` 拿 m3u8，用 Media3 `DownloadManager`/`SimpleCache` 或自写分片下载合并为本地缓存；列表项显示下载状态，播放时优先本地文件。视频可选做（体积大，建议仅 Wi-Fi + 手动）。
- **改动**：新增 `MediaDownloader` + 下载任务表（可复用 `CourseCache` 的 SharedPreferences 结构或引入 Room）；`AudioPlaybackService.playFile` 增加本地文件分支。
- **难度**：M–L。

#### 6. 多账号快速切换
- **价值**：`AccountScope` 已经按 `uk` 隔离数据，只差一个切换入口；家庭/多号用户常换号。
- **做法**：设置页加「账号列表 / 切换账号」，切换后清 WebView 会话并重新校验；本地收藏、历史天然按账号分桶。
- **难度**：S–M。

#### 7. 收藏分组 / 自建课程包 / 播放列表
- **价值**：收藏一多就是一团；用户想「按考试/专题」组织课程，并按自定义顺序连播。
- **做法**：`Favorites` 从扁平列表升级为「分组 → 条目」；新增「播放列表」概念，可从任意目录「加入列表」，列表内可拖动排序，播放器按列表顺序连播（复用现有 `QueueSelection`/`orderCourses`）。
- **难度**：M。

### P1 · 内容增强（依托百度同源 AI 接口，差异化最强）

> 依据 `docs/视频AI功能接口与权益方案.md`：这些接口都在 `pan.baidu.com` 同源、Cookie 鉴权，和现有取流同一套 WebView 代发方式，**不需要逆向 sign**。免费可用：播放/下载/视频笔记/AI 问答；受限：视频总结（完整）、智能字幕（试用额度外需 SVIP/视频券）。

#### 8. 视频 AI 智能总结（AI 课件）
- **价值**：课程视频直接生成幻灯片式总结，复习效率高。
- **做法**：`GET /aitrans/ppt/get?fsid&share_uk&client_type=2` 取**已生成**课件图片（`data.list[].img_url`，签名 CDN 可直接展示）；免费号可看前 5 页，超出引导「用视频券/升级 SVIP」。生成走 `ppt/common`、导出走 `ppt/export`（method 待实测）。
- **改动**：视频播放页加「AI 总结」入口 → 图片画廊页；`PanApi` 新增 ppt 系列。
- **难度**：M。

#### 9. AI 智能字幕 / 逐字稿
- **价值**：听不清/外语/倍速复习；逐字稿可导出成文档存回网盘。
- **做法**：`/richsearch/autosubtitle/common?method=apply|status|query` 申请与轮询状态，拿到字幕后 `POST /transapi/autosubtitle/exportvideoscript` 导出 `.doc` 到网盘。
- **难度**：M。

#### 10. 视频笔记 / 打点标记
- **价值**：暂停即记笔记、按时间点跳回，学习闭环。
- **做法**：`/api/videomark/note?method=query&vfsid=<页面真实 vfsid>`（注意 vfsid ≠ fs_id，需从播放页文件对象取）；播放器时间轴显示打点，点击跳转。
- **难度**：M。

#### 11. AI 问答侧栏
- **价值**：围绕视频内容提问、推荐相关工具。
- **做法**：`/aisearch/user/get` 判断开关，`/aisearch/sidebar/status`、`/aisearch/recommend/tool` 接入侧栏。
- **难度**：M。

#### 12. 播放清晰度切换 + 外挂字幕
- **价值**：弱网降清晰度、强网提清晰度；已有 HLS 链路，扩展成本低。
- **做法**：`stream_type` 在 `M3U8_AUTO_480/720/1080` 间切换；字幕可先支持用户本地 `.srt/.vtt` 选择，再考虑接 AI 字幕。
- **难度**：S–M。

### P2 · 网盘文件管理（从「只读浏览」升级为「可管理」）

> 当前 `ic_upload` 等图标已存在但未使用；网盘页实际是只读。若产品定位是「课程播放器」可保持只读；若想覆盖「整理转存资料」的用户，这是最大的体验补齐点。

- **13. 新建文件夹 / 重命名 / 移动 / 复制 / 删除**：走网盘文件管理接口（`/api/create`、`/api/filemanager` 等），加长按菜单 + 二次确认 + 失败回滚提示。
- **14. 上传文件**：调起系统文件选择 → 分片上传（`/api/create`+`/rest/2.0/pcs/superfile2`）。
- **15. 分享 / 转存**：生成分享链接；把群文件「转存到我的网盘」——这条与「已转存」标记形成闭环，价值高。
- **难度**：M–L（接口多、错误码多，建议单独排期）。

## 四、技术约束与落地注意

1. **同源 Cookie 是生命线**：所有接口都在 `pan.baidu.com` 的隐藏 WebView 内 `fetch`，不能退化成裸 HTTP 重放；私有接口无契约，前端发版可能改参数，需容错与降级。
2. **权益门槛**：视频总结（完整）、智能字幕生成受 SVIP/视频券限制；App 应做「查看已生成结果 + 引导用户用券/升级」，不要把生成成本压给客户端。
3. **vfsid ≠ fs_id**：视频笔记必须用播放页真实 `vfsid`，不能拿列表的 `fs_id` 硬拼。
4. **地址时效**：m3u8/dlink 约 8 小时有效，必须播前现取、失败重取，绝不持久化 URL（现有 `MediaAddressCache` 6h TTL 已是正确做法）。
5. **离线下载存储**：优先音频、仅 Wi-Fi、可一键清理；下载目录纳入「存储」设置项与备份白名单之外（媒体文件不进 JSON 备份）。
6. **多账号隔离**：任何新增本地数据（下载任务、播放列表、统计）都必须走 `AccountScope.key()` 分桶，避免串号。

## 五、优先级一句话结论

- **马上做**：全局搜索、睡眠定时、未听筛选、多账号切换、批量收藏——全部 S 级、当天到两三天可交付。
- **最值得做**：音频离线下载 + 收藏分组/播放列表——直接决定「通勤听课」核心场景。
- **最有差异化**：视频 AI 总结 / 字幕 / 笔记——已有同源接口验证，别人抄不动。
- **看定位决定**：网盘文件写操作（上传/转存/删除）——想从「播放器」变「网盘工具」再做。
