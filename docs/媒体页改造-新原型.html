五、这套原型遵循的规则

P1

一屏一个主体

视频是画面、音频是圆形封面、图片是原图。课程列表、来源/状态、多余文字全部收走。

P2

控制一行、沉到底部

视频三行控制层压成一行并叠在画面内底部，不再占位；音频动作栏 + 进度 + 传输组集中在底部一坨，中间大留白。

P3

顶栏轻、动作收进 ···

透明 scrim + 两行标题；高频的转音频常驻顶栏耳机，低频的收藏/定时/文件信息进弹层；竖屏已有课程列表，不重复放入口。

夸克有，我们判定原因
AI 总结 / 文稿 / 转文字不做无能力、无接口，全库无相关代码
字幕 / 投屏 TV不做无字幕数据、无 Cast 依赖
1080p / 超清切换不做服务端只给单档 M3U8_AUTO_480
修图 / 拍摄地点不做无图像编辑、无 EXIF 地点
视频 Tab / 文件详情页不做我们是 Dialog/覆盖式 View，无页面栈与底部导航
转音频保留我们独有（夸克没有）；高频使用，竖屏顶栏常驻耳机，横屏不设
选集缩略图 / 已观看%可做复用首页 loadRecentThumbnail + 本地进度

原型为交互示意，尺寸按真机 1224×2700 等比缩放。对应方案文档：docs/媒体页改造方案-基于实际能力.md；竞品实拍对照：docs/夸克真机对比诊断.html。本页不改动任何业务代码。
