# 夸克网盘 · 图片地址分析（缩略图 / 看图大图，不走下载）

> 版本：v1.0　生成日期：2026-11-10
> 适用：`pan.quark.cn` 网页版（登录态）；目标——**不经过 `file/download`（下载原文件）**，直接拿到图片的展示地址。
> 证据来源：前端包 `uc-cloud-drive-web-system/cloud-drive-web/4.6.7/index.js` 静态分析（S）+ 真实登录态实测（R，2026-11-10）。
> 关联：`docs/夸克网盘接口分析.md`（整体接口）、`docs/多网盘整合架构方案.md`。

---

## 0. 结论：图片有 4 种地址，都不走 `file/download`

| 用途 | 字段 / 接口 | 地址形态 | 鉴权 | 实测 |
|---|---|---|---|---|
| 列表小图（宫格/图标） | 文件项 `thumbnail` | `https://drive-pc.quark.cn/1/clouddrive/file/thumbnail?fid=<fid>` | **需 Cookie**（无 cookie → `401 code=31001 require login`） | ✅ R |
| 列表大图 / 封面 | 文件项 `big_thumbnail`（等于 `/quick?fid=`） | `https://drive-pc.quark.cn/1/clouddrive/file/quick?fid=<fid>` | **需 Cookie** | ✅ R |
| **看图大图（推荐）** | 文件项 `preview_url` / `advanced_preview[].preview_url` | `https://img-view-*.drive.quark.cn/<hash...>/preview?auth_key=…&sp=100&token=…&ork=…&ud=…&dfi=152` | **免 Cookie**（OSS/CDN 预签名，约 3h） | ✅ R |
| 看图翻页取址 | `GET /1/clouddrive/file/advanced_preview` | 返回数组，每项含 `preview_url` | 需 Cookie 调接口 | ✅ R |

> **关键点**：`preview_url` 是**预签名的图片视图 CDN 地址**，直接返回**已优化的 WebP**（实测原图 131KB jpg → preview 29KB、733×695 WebP），**无需 Cookie、无需下载原文件**。这是“看图”场景最省事、最该用的地址。

## 1. 字段从哪来（实测样例）

图片文件在以下接口的**文件项**里都会带 `thumbnail`、`big_thumbnail`、`preview_url` 三个字段（实测 R）：

- `GET /1/clouddrive/file/sort`（目录列表）
- `GET /1/clouddrive/file/category?cat=image`（图片分类）

实测（`cat=image`，2026-11-10）：

- 图片判定：`category == 3`，`format_type` 形如 `image/jpeg`。（图片扩展名集合见前端：jpg/jpeg/png/gif/webp/bmp/heic/svg/psd/tiff）

## 2. 三种地址详解

### 2.1 `thumbnail` / `quick`（列表缩略图，需 Cookie）

- 形态固定：`https://drive-pc.quark.cn/1/clouddrive/file/thumbnail?fid=<fid>` 与 `.../file/quick?fid=<fid>`。
- 前端源码里二者等价互换：`Q(thumbnail).replace("/thumbnail?","/quick?")`——`big_thumbnail` 字段本身就是 `quick` 版本（实测二者一致）。
- **必须带登录 Cookie**：无 Cookie 实测返回 `HTTP 401`，body `{"status":401,"code":31001,"message":"require login [auth not found]"}`。
- 前端实际取图标时会再拼公共参数 `?pr=ucpro&fr=pc`（`Q()`），IE/Safari 额外 `&format=png`；对 OkHttp/WebView 请求可省略。
- 适合：列表宫格、缩略图。**优点**：URL 短、可长期缓存（同一 fid 不变）；**缺点**：需 Cookie，且是服务端固定尺寸。

### 2.2 `preview_url`（看图大图，免 Cookie，推荐）

- 形态：`https://img-view-<region>.drive.quark.cn/<路径hash>/preview?auth_key=…&sp=100&token=…&ork=…&ud=…&dfi=152`。
- **预签名、免 Cookie**：`curl`（不带任何 Cookie）实测 `HTTP 200`、`content-type: image/webp`、29642 字节、真实 WebP 733×695。原图 jpg 是 134695 字节 → CDN 已返回**压缩优化后的 WebP**。
- 有效期约 **3 小时**（`auth_key` 的 `10800` 秒）；**每次加载都应重新取**，不要持久化。
- 适合：点开看图、详情大图、预览弹窗——**这是“不走下载”的标准做法**。

> ⚠️ **`x-oss-process` 对 `preview_url` 无效**（实测）：在 `preview_url` 后追加 `&x-oss-process=image/resize,w_320/quality,q_80` 返回内容与不加完全一致（同样 29642 字节、733×695）。因为它是 img-view 图片服务而非裸 OSS 对象。前端 `imageCompress()` 拼的 `x-oss-process=image/resize,w_750/quality,q_90[/format,x]` 只对**OSS 直链**（如 `download_url`）有效，不适用于 `preview_url`。

### 2.3 `advanced_preview`（看图器取址 / 上下翻页）

看图器（`imgpreview`）真正调用的取址接口。前端 `showViewer()` 用它一次性拿到当前图片及前后若干张的 `preview_url`：

```
GET https://drive-pc.quark.cn/1/clouddrive/file/advanced_preview
    ?pr=ucpro&fr=pc
    &pdir_fid=<当前目录 fid>
    &cat=image                // 固定 image
    &_sort=updated_at:desc    // 排序字段:方向
    &_size=15                 // 前后各取几张（前端固定 15）
    &cur_fid=<当前图片 fid>
    &cur_value=<当前图片在该排序字段上的值，如 l_updated_at>
    &direction=after|before
    &format=                  // 可空；ie/safari 传 png
```

- **返回 `data` 是数组**（实测 `isArray:true`，5 项），每项字段含：`fid, file_name, pdir_fid, category, format_type, size, l_updated_at, preview_url, obj_category, …`
- **注意：`advanced_preview` 的数组项只带 `preview_url`，不带 `thumbnail`/`big_thumbnail`**（实测 `firstKeys` 无这两个字段）。看图器直接用 `item.preview_url` 作为 `<img src>`。
- 前端还有 `preview_trans_status`（转码/预览状态）：就绪的图片一般无该字段或为完成态；若未就绪需稍等再取。
- 用途：既能取当前图，也能拿相邻图做左右翻页（`direction` + `cur_value` 定位），一次请求即可预取前后图。

## 3. 分享态图片（补充）

分享页看图走另一条：`zt.w({pwd_id, fid_list, fid_token_list, stoken, format:"png"})` → 对应 `POST /1/clouddrive/share/sharepage/preview`（或 `share/download`）。分享图片需要 `pwd_id` / `stoken` / `fid_token`，与个人网盘不同；本文主线为个人网盘登录态。

## 4. 客户端落地建议（`QuarkPersonalDrive` 扩展）

当前 `QuarkFile` 只有 `id/name/directory/size/mtime`，**没有图片字段**。建议：

1. **扩展 `QuarkFile`**，解析列表/category 时补齐：
   ```kotlin
   data class QuarkFile(
       val id: String, val name: String, val directory: Boolean,
       val size: Long = 0, val mtime: Long = 0,
       val pdirId: String = "",          // 父目录 fid（看图 advanced_preview 需要）
       val updatedAt: Long = 0,          // = l_updated_at，作为 cur_value
       val thumbnail: String = "",       // 列表小图（需 cookie）
       val bigThumbnail: String = "",    // 列表大图=quick（需 cookie）
       val previewUrl: String = "",      // 看图大图（免 cookie，3h）
   )
   ```
   解析：`thumbnail=optString("thumbnail")`、`bigThumbnail=optString("big_thumbnail")`、`previewUrl=optString("preview_url")`、`pdirId=optString("pdir_fid")`、`updatedAt=optLong("l_updated_at")`。

2. **看图大图**：优先用列表项里的 `preview_url`；翻页时调 `advancedPreview(pdirId, curFid, curValue=updatedAt, direction)` 拿相邻图的 `preview_url`。

3. **列表缩略图**：`thumbnail`/`bigThumbnail` 需要 Cookie——用现有 `QuarkPersonalDrive.request()`（自带 Cookie）下载成 Bitmap，或让隐藏 WebView 加载。**不要**为了缩略图去调 `file/download`。

4. **不要缓存 `preview_url` 超过其时效**：签名约 3h，建议内存缓存但每次打开前判过期重取；`thumbnail` 因同一 fid URL 稳定可长缓存（但请求仍需 Cookie）。

5. **新增方法（示意，未落地）**：
   ```kotlin
   fun advancedPreview(pdirFid: String, curFid: String, curValue: Long, direction: String = "after", size: Int = 15): List<QuarkFile> {
       val json = request(url("file/advanced_preview",
           "pdir_fid" to pdirFid, "cat" to "image", "_sort" to "updated_at:desc",
           "_size" to "$size", "cur_fid" to curFid, "cur_value" to "$curValue",
           "direction" to direction, "format" to ""))
       val arr = json.getJSONArray("data")   // 注意 data 是数组
       return List(arr.length()) { i -> parseImageItem(arr.getJSONObject(i)) }
   }
   ```

## 5. 实测记录（2026-11-10，R）

| 项 | 请求 | 结果 |
|---|---|---|
| 图片分类字段 | `GET file/category?cat=image` | 项含 `thumbnail / big_thumbnail / preview_url / l_updated_at / category=3`（R） |
| 图片目录字段 | `GET file/sort?pdir_fid=<图片目录>` | 同一图片项同样带三字段（R） |
| `preview_url` 免 Cookie | `curl` 直接 GET（无 Cookie） | `HTTP 200`，`image/webp`，29642B，733×695 WebP（R） |
| `preview_url` + x-oss-process | GET `...&x-oss-process=image/resize,w_320` | 与不加完全一致（29642B），**说明对 preview_url 无效**（R） |
| `thumbnail` 无 Cookie | GET `file/thumbnail?fid=`（无 Cookie） | `HTTP 401`，`code=31001 require login`（R） |
| `quick`=big_thumbnail | 字段比对 | `big_thumbnail` 即 `/file/quick?fid=`，与 `thumbnail` 仅路径不同（R） |
| `advanced_preview` | `GET file/advanced_preview?pdir_fid&cat=image&cur_fid&cur_value&direction` | `code=0`，`data` 为数组(5 项)，项含 `preview_url`、**无** `thumbnail/big_thumbnail`（R） |
| 签名时效 | `auth_key=<ts>-…-10800-<hash>` | 约 10800 秒（3h），每次重新签发（R/S） |

## 6. 小结（给客户端的一句话）

- **列表**：用 `thumbnail`（小）/ `big_thumbnail`（`quick`，大）——需 Cookie，URL 稳定可缓存。
- **看图**：用 `preview_url`——**免 Cookie 的预签名 WebP 大图**，3 小时有效，每次现取；翻页用 `advanced_preview` 批量拿相邻 `preview_url`。
- 全程**不碰 `file/download`**，既省一次下载请求，也避免拿原图大文件。
